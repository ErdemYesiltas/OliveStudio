# 3D Photo Demo

Open **Hub → Examples → 3D Photo Demo** or open [the project file](3d-photo.json). Use the **Scenes** panel to switch between the garage and **Moss Locksmith**. Move the pointer across either photo in Edit or Live. The picture returns to its neutral pose when the pointer leaves the canvas.

Select **Garage photo** and expand **Inspector → Effects → 3D Photo** to see the map and change strength on either axis. The original 260 × 195 images are embedded in the scene. The demo displays them at 3× scale and scales the displacement by the same factor.

The color and depth images are the garage pair from the upstream demo. The upstream author credits Red Stapler for the tutorial imagery. [Upstream images](https://github.com/ParkYoungWoong/pixi-3d-photo/tree/55d27fdabf086762eb3e2842fc57e0a4e2a396bb/assets) · [Upstream credits](https://github.com/ParkYoungWoong/pixi-3d-photo#3d-photo-generator-by-pixijs)

The **Moss Locksmith** scene pairs an original ImageGen frog portrait with a depth map derived from the character silhouette and a shallow forest floor gradient.

- Character prompt asked for a green frog locksmith with a knitted scarf and brass key on a moss-covered stone, isolated on transparency.
- Background prompt asked for a sunlit miniature woodland clearing with ferns and mushrooms at the edges and open space in the middle.
